# Java Number System Converter

## Description
This project is a Java Swing application that converts numbers between Decimal, Binary, Octal, and Hexadecimal numbering systems.

## Features
- Convert between Decimal, Binary, Octal, and Hexadecimal.
- Real-time conversion while typing.
- Input validation for each numbering system.
- Automatic update of all equivalent values.
- User-friendly graphical interface built with Java Swing.

## Technologies
- Java
- Java Swing
- NetBeans IDE

## Supported Number Systems
- Decimal (Base 10)
- Binary (Base 2)
- Octal (Base 8)
- Hexadecimal (Base 16)

## How to Use
1. Run the application.
2. Select the input number system.
3. Enter a valid number.
4. The equivalent values in the other numbering systems are displayed automatically.

## Example

Input:
```
255
```

Selected Input Type:
```
Decimal
```

Output:
```
Decimal      : 255
Binary       : 11111111
Octal        : 377
Hexadecimal  : FF
```
